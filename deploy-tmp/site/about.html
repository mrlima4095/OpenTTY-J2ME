About this demo

A handful of files in /home/web, served straight from a MIDlet.

What is running

  • OpenTTY - a Lua shell for J2ME (CLDC 1.1 / MIDP 2.0).
  • nginx app - the HTTP server from the on-device app store.
  • This site - three static files and a status page.

Try it

curl http://DEVICE-IP/
curl http://DEVICE-IP/nginx-status
nginx reload
