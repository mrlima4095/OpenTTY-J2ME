Served by nginx on a J2ME phone

This page is a static file from /home/web on the device, handed out by the OpenTTY nginx app running on the MIDlet.

Small

No external dependencies. Every byte travels over the phone's Wi-Fi.

Plain

Static files, a few MIME types and a /nginx-status page.

Yours

Drop an index.html in /home/web and reload.

Server status

loading /nginx-status ...

How it is wired

listen 80;
root /home/web/;
index index.html;

The config lives in /etc/nginx/nginx.conf and is read at startup; nginx reload picks up edits without dropping the site.
